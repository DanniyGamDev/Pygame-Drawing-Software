This is a simple drawing software I'm making with pygame. It's basic but I started this to try and see what pygame can do, other than its original purpose.  

The main thing that hooked me was pygame's draw function, which automatically draws stuff for you. It seems simple, because well, it is, but I wanted to try
and see what it could do. It's certainly not what what you'd consider pygame's traditional use to be, but a fun project nonetheless. 
This isn't anything fancy, just a couple of simple functions.
